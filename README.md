# UI-автотесты practice-automation.com

Автотесты учебного сайта practice-automation.com: страницы Calendars, Modals, Ads и Form Fields.
Стек: Python 3.12+, Selenium 4, Pytest, Allure. Архитектура - Page Object: страницы в `pages/`, проверки в `tests/`.
Поддерживаются Chrome и Firefox, драйверы Selenium скачивает сам.

## Установка

```bash
python -m venv .venv
.venv\Scripts\activate        # Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
```

Достаточно, чтобы на машине был установлен Chrome или Firefox.

## Запуск

```bash
pytest                          все тесты в Chrome
pytest -v                       то же с выводом каждого теста
pytest --headless               браузер без окна
pytest --browser=firefox        в Firefox
pytest tests/test_calendar.py   тесты одной страницы
pytest -n 3                     параллельно в 3 процесса
```

## Отчёт Allure

Результаты каждого запуска сохраняются в папку `allure-results`. Для просмотра нужен
установленный [Allure Commandline](https://allurereport.org/docs/install-for-commandline/):

```bash
pytest
allure serve allure-results
```

При падении теста отчёт автоматически прикрепляет скриншот браузера в момент ошибки.

## Сценарии

### Календарь — /calendars/

Позитивные:
- Страница открывается, заголовок Calendars
- Клик по полю даты открывает календарь
- Календарь открывается на текущем месяце и годе
- Сегодняшний день выделен в календаре
- Выбор сегодняшней даты записывает её в поле в формате ГГГГ-ММ-ДД
- Выбор даты в прошлом месяце, следующем месяце и другом году (параметризованный)
- Дату можно ввести вручную в формате ГГГГ-ММ-ДД
- Форма с выбранной датой отправляется, появляется подтверждение

Негативные:
- Календарь скрыт, пока не кликнули по полю даты
- Клик вне календаря закрывает его, поле остаётся пустым
- Esc закрывает календарь, дата не выбирается
- Дни соседних месяцев в сетке отмечены отдельно и не входят в текущий месяц

### Модальные окна — /modals/

Позитивные:
- Страница открывается, заголовок Modals, обе кнопки на месте
- После загрузки страницы обе модалки скрыты
- Simple Modal открывается по кнопке
- Simple Modal содержит заголовок и текст
- Simple Modal закрывается кнопкой ×
- Simple Modal можно открыть повторно после закрытия
- Form Modal открывается, виден заголовок и подсказка
- В Form Modal есть поля Name, Email, Message и кнопка Submit
- Form Modal закрывается кнопкой ×
- Форма с корректными данными отправляется, появляется подтверждение

Негативные:
- Сайт не валидирует форму: пустая форма принимается, появляется подтверждение
- Сайт не проверяет email: некорректные значения принимаются (параметризованный)
- Клавиша Esc не закрывает Simple Modal
- При открытой Simple Modal Form Modal не отображается

### Рекламные окна — /ads/

Позитивные:
- Страница открывается, заголовок Ads
- На странице виден текст про отсчёт и описание
- Реклама появляется автоматически через несколько секунд
- Рекламное окно содержит заголовок Hi и текст I am an ad
- В рекламном окне отображается кнопка закрытия
- Реклама закрывается кнопкой ×
- После закрытия рекламы ссылка Learn More доступна и ведёт на linktr.ee
- Если не закрывать рекламу, после обновления страницы она появляется снова

Негативные:
- Закрытая реклама не появляется повторно на той же странице
- Вместе с рекламой не открываются другие модальные окна
- Клавиши Tab, X, стрелка вниз и Esc не закрывают рекламу
- Пока открыта реклама, ссылки под ней недоступны

### Форма — /form-fields/

- Поле Message заполняется списком из раздела Automation Tools: элементы списка берутся
  через Selenium, склеиваются через ", ".join и вводятся в поле
- В списке Automation Tools есть Selenium
- Заполненная форма отправляется, появляется алерт Message received!
