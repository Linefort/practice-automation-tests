Проект автоматизированных UI-тестов для учебного сайта [practice-automation.com](https://practice-automation.com/).
Покрыты четыре страницы: календарь, модальные окна, рекламные окна и форма. Всего 45 тестов,
полный прогон занимает около двух минут в три потока.

| | |
|---|---|
| Язык | Python 3.12+ |
| Автоматизация браузера | Selenium 4 (драйверы скачиваются автоматически) |
| Тестовый фреймворк | Pytest, параллельный запуск через pytest-xdist |
| Отчёты | Allure, скриншот при любом падении теста |
| Браузеры | Chrome (по умолчанию) и Firefox |
| Архитектура | Page Object Model |

## Быстрый старт

```bash
python -m venv .venv
.venv\Scripts\activate        # Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
pytest -n 3
```

Больше ничего настраивать не нужно: на компьютере должен быть установлен Chrome или Firefox,
подходящий драйвер Selenium скачает сам.

## Команды запуска

| Команда | Что делает |
|---|---|
| `pytest` | все тесты последовательно в Chrome |
| `pytest -n 3` | все тесты параллельно в три процесса |
| `pytest --browser=firefox` | запуск в Firefox |
| `pytest --headless` | браузер без окна, удобно для сервера |
| `pytest tests/test_calendar.py` | тесты одной страницы |
| `pytest -k Negative` | только негативные тесты |
| `pytest -k Positive` | только позитивные тесты |
| `pytest -v` | подробный вывод каждого теста |

## Отчёт Allure

Результаты каждого запуска сохраняются в папку `allure-results`. Чтобы открыть отчёт, нужен
[Allure Commandline](https://allurereport.org/docs/install-for-commandline/) (ему требуется Java):

```bash
pytest -n 3
allure serve allure-results
```

В отчёте:
- название каждого теста и каждого шага на русском языке;
- результат по каждому тесту и параметризованному случаю;
- скриншот страницы, который прикрепляется автоматически, если тест упал.

## Как устроен проект

| Файл или папка | Назначение |
|---|---|
| `conftest.py` | запуск браузера, опции `--browser` и `--headless`, фикстуры страниц, хук скриншота при падении |
| `pages/base_page.py` | базовый класс страницы: все явные ожидания и общие действия (клик, ввод, поиск) |
| `pages/calendar_page.py` | страница календаря |
| `pages/modals_page.py` | страница модальных окон |
| `pages/ads_page.py` | страница рекламных окон |
| `pages/form_fields_page.py` | страница с формой |
| `pages/popup_page.py` | общие XPath для всплывающих окон, которые используют страницы Modals и Ads |
| `tests/` | тесты, по одному файлу на страницу |
| `pytest.ini` | настройки Pytest и Allure |

Принципы, которые соблюдаются в коде:
- Страницы не содержат проверок, а тесты не обращаются к Selenium напрямую. Тесты читаются как
  последовательность действий пользователя.
- Все ожидания явные и находятся в `BasePage`. Задержек `time.sleep()` в проекте нет.
- Каждый тест запускает свой браузер, поэтому тесты независимы и их можно запускать в любом порядке и параллельно.
- Для ускорения Chrome запускается с ранней стратегией загрузки страницы и блокирует сторонние
  рекламные и аналитические домены, которые на проверки не влияют.

## Особенности сайта, которые учтены в тестах

- Календарь на странице Calendars не использует jQuery UI. Это собственный виджет, и в тестах он
  описан по его реальной разметке: переключение месяцев идёт кнопками «назад» и «вперёд».
- Всплывающие окна на страницах Modals и Ads не закрываются клавишей Esc, только кнопкой с крестиком.
  Это зафиксировано негативными тестами.
- Форма внутри модального окна не проверяет введённые данные: пустая форма и email неверного
  формата принимаются. Негативные тесты формы фиксируют именно такое фактическое поведение сайта.
- Реклама на странице Ads появляется примерно через 5 секунд после загрузки, поэтому ожидание её появления
  вынесено в отдельный метод с увеличенным таймаутом.

## Тестовые сценарии

Параметризованные тесты в списках ниже считаются за один сценарий. В Pytest каждый их случай
запускается отдельно.

### Календарь (`/calendars/`)

Позитивные сценарии:

| № | Сценарий | Ожидаемый результат |
|---|---|---|
| 1 | Открыть страницу | Заголовок вкладки и страницы Calendars |
| 2 | Кликнуть по полю даты | Открывается календарь |
| 3 | Открыть календарь | Показан текущий месяц и год |
| 4 | Открыть календарь | Сегодняшний день выделен |
| 5 | Выбрать сегодняшнюю дату | В поле записана дата в формате ГГГГ-ММ-ДД |
| 6 | Выбрать 15 число в прошлом месяце, в следующем месяце и через 14 месяцев (три случая) | В поле записана выбранная дата |
| 7 | Ввести дату вручную `2025-01-15` | Значение сохраняется в поле |
| 8 | Выбрать дату и нажать Submit | Появляется сообщение «Thank you for your response» |

Негативные сценарии:

| № | Сценарий | Ожидаемый результат |
|---|---|---|
| 1 | Открыть страницу и не кликать по полю | Календарь скрыт |
| 2 | Открыть календарь и кликнуть вне его | Календарь закрывается, поле остаётся пустым |
| 3 | Открыть календарь и нажать Esc | Календарь закрывается, дата не выбирается |
| 4 | Открыть календарь | Дней текущего месяца столько, сколько в самом месяце, дни соседних месяцев отмечены отдельно |
