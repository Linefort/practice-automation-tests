# UI-автотесты для practice-automation.com

Автотесты для страниц с упражнениями: календарь, модальные окна, рекламные окна и форма.

Стек: Python 3.12+, Selenium, Pytest, Allure. Тесты написаны по шаблону Page Object: действия со страницами лежат в папке pages, сами проверки в папке tests. Поддерживаются браузеры Chrome и Firefox, драйверы Selenium скачивает сам.

## Установка

    python -m venv .venv
    .venv\Scripts\activate          (Linux/macOS: source .venv/bin/activate)
    pip install -r requirements.txt

## Запуск тестов

    pytest                          все тесты в Chrome
    pytest --browser=firefox        все тесты в Firefox
    pytest tests/test_calendar.py   тесты одной страницы
    pytest -k Negative              только негативные тесты
    pytest -k Positive              только позитивные тесты

## Отчёт Allure

Результаты каждого запуска сохраняются в папку allure-results. Для просмотра нужен установленный Allure Commandline:

    pytest
    allure serve allure-results

При падении теста в отчёт автоматически прикрепляется скриншот.

## Тестовые сценарии

### Календарь (https://practice-automation.com/calendars/)

Позитивные:
- Страница открывается, заголовок Calendars
- Клик по полю даты открывает календарь
- Календарь открывается на текущем месяце
- Сегодняшний день выделен в календаре
- Выбор сегодняшней даты записывает её в поле в формате ГГГГ-ММ-ДД
- Выбор даты в следующем месяце
- Выбор даты в предыдущем месяце
- Выбор даты в другом году (через 14 месяцев)
- Ввод даты вручную
- Отправка формы с выбранной датой, появляется подтверждение

Негативные:
- Календарь скрыт, пока не кликнули по полю даты
- Клик вне календаря закрывает его, поле остаётся пустым
- Esc закрывает календарь, дата не выбирается
- Для выбора доступны только дни текущего месяца

### Модальные окна (https://practice-automation.com/modals/)

Позитивные:
- Страница открывается, заголовок Modals, обе кнопки на месте
- После загрузки страницы обе модалки скрыты
- Simple Modal открывается по кнопке
- Simple Modal содержит заголовок и текст
- Simple Modal закрывается кнопкой ×
- Simple Modal закрывается клавишей Esc
- Form Modal открывается, виден заголовок и подсказка
- В Form Modal есть поля Name, Email, Message и кнопка Submit
- Form Modal закрывается кнопкой ×
- Форма с корректными данными отправляется, появляется подтверждение

Негативные:
- Пустая форма не отправляется
- Форма без имени не отправляется, хотя остальные поля заполнены
- Email в неверном формате не принимается
- При открытой Simple Modal Form Modal не отображается

### Рекламные окна (https://practice-automation.com/ads/)

Позитивные:
- Страница открывается, заголовок Ads
- На странице виден текст про отсчёт и описание
- Реклама появляется автоматически через несколько секунд
- В рекламном окне есть текст I am an ad
- Заголовок рекламного окна Hi
- В рекламном окне отображается кнопка закрытия
- Реклама закрывается кнопкой ×
- Реклама закрывается клавишей Esc
- После закрытия рекламы ссылка Learn More доступна и ведёт на linktr.ee
- Если не закрывать рекламу, после обновления страницы она появляется снова

Негативные:
- Закрытая реклама не появляется повторно на той же странице
- Вместе с рекламой не открываются другие модальные окна
- Посторонние клавиши (Tab, X, стрелка вниз) не закрывают рекламу
- Пока открыта реклама, ссылки под ней недоступны

### Форма (https://practice-automation.com/form-fields/)

- Поле Message заполняется списком из раздела Automation Tools: элементы списка берутся через Selenium, склеиваются через запятую и вводятся в поле
- В списке Automation Tools есть Selenium
- Заполненная форма отправляется, появляется алерт Message received!
